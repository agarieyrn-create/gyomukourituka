# GAS 予約管理ツール

Google Apps Script（GAS）で動作する予約管理ツールです。
個人サロン・治療院・飲食店など、複数スタッフで共有できる汎用設計になっています。

## 機能一覧

- **オンライン予約受付**：月カレンダー → 時間枠選択 → 予約フォームのSPA構成
- **予約キャンセル**：予約IDと氏名で検索・キャンセル
- **予約変更**：予約IDと氏名で検索・新しい日時を選択して変更
- **Googleカレンダー連携**：予約登録・変更・キャンセル時にカレンダーイベントを自動管理
- **メール自動送信**：予約確認・変更通知・キャンセル通知・リマインダー
- **ダッシュボード**：今日の予約・週次/月次集計・ステータス別件数・グラフ
- **休業日管理**：定休日（曜日指定）+ 臨時休業日（日付指定）
- **二重予約防止**：LockServiceによる同時リクエスト制御

## セットアップ手順

### 1. スプレッドシートを作成

1. Google スプレッドシートを新規作成します
2. メニューから「拡張機能」→「Apps Script」を開きます

### 2. GASコードをコピー

以下のファイルをApps Scriptエディタにコピーしてください：

| ファイル名 | 役割 |
|---|---|
| `Code.gs` | メイン・ルーティング（doGet / doPost） |
| `calendar.gs` | カレンダー・空き状況管理 |
| `sheet.gs` | スプレッドシート操作 |
| `mail.gs` | メール送信処理 |
| `reminder.gs` | リマインダー送信 |
| `holiday.gs` | 休業日管理 |
| `cancel.gs` | キャンセル処理 |
| `change.gs` | 予約変更処理 |
| `setup.gs` | セットアップ・カスタムメニュー |

HTMLファイルも同様にApps Scriptエディタに追加してください：

| ファイル名 | 役割 |
|---|---|
| `index.html` | 予約カレンダー（メイン画面） |
| `cancel.html` | キャンセルフォーム |
| `change.html` | 変更フォーム |

`appsscript.json` の内容も反映してください（エディタの設定で「appscript.json マニフェストをエディタで表示する」をONにして編集）。

### 3. 初回セットアップを実行

1. スプレッドシートに戻り、ページを再読み込みします
2. メニュー「⚙️ 予約ツール設定」→「初回セットアップ」を実行します
3. 以下のシートとサンプルデータが自動作成されます：
   - 予約一覧
   - メニューマスタ（サンプルメニュー5件入り）
   - 設定（デフォルト値入り）
   - 臨時休業日（サンプル入り）
   - キャンセル・変更履歴
   - ダッシュボード

### 4. 設定シートを編集

「設定」シートで以下の項目を編集してください：

| 設定項目 | 説明 | 例 |
|---|---|---|
| 営業開始時間 | 予約受付の開始時間 | 10:00 |
| 営業終了時間 | 予約受付の終了時間 | 19:00 |
| 予約間隔（分） | 予約枠の間隔 | 60 |
| 同時受付数 | 同じ時間帯に受けられる予約数 | 1 |
| 定休日曜日 | カンマ区切りで曜日を指定 | 月曜,火曜 |
| 管理者メールアドレス | 通知を受けるメールアドレス | admin@example.com |
| 店舗名 | ヘッダーやメールに表示される名前 | サンプルサロン |
| 共通GoogleカレンダーID | カレンダー連携用のID | xxxxx@group.calendar.google.com |
| 予約受付期間（何日先まで） | 何日先まで予約を受けるか | 30 |
| リマインダー送信タイミング | 予約日の何日前にリマインダーを送るか | 1日前 |

### 5. メニューマスタを編集

「メニューマスタ」シートで、自店舗のメニューを設定してください。

| メニューID | メニュー名 | 所要時間（分） | 料金 |
|---|---|---|---|
| MENU-001 | カット | 60 | 4000 |
| MENU-002 | カット＋カラー | 120 | 8000 |

### 6. Googleカレンダーの設定（任意）

1. Googleカレンダーで予約管理用のカレンダーを作成します
2. カレンダーの設定から「カレンダーID」をコピーします
3. 設定シートの「共通GoogleカレンダーID」に貼り付けます

### 7. Web Appとしてデプロイ

1. Apps Scriptエディタで「デプロイ」→「新しいデプロイ」を選択
2. 種類：「ウェブアプリ」を選択
3. 次のユーザーとして実行：「自分」
4. アクセスできるユーザー：「全員」
5. 「デプロイ」をクリック
6. 表示されたURLが予約ページのURLです

## トリガー設定

### リマインダートリガー（自動設定済み）

初回セットアップ時に自動設定されますが、手動で設定する場合：

1. メニュー「⚙️ 予約ツール設定」→「リマインダートリガーを設定」

または Apps Script エディタから：

1. 「トリガー」→「トリガーを追加」
2. 関数：`sendReminders`
3. イベントソース：時間主導型
4. 時間ベースのトリガー：日付ベースのタイマー
5. 時刻：午前8時〜9時

## URL構成

| URL | 画面 |
|---|---|
| `{Web App URL}` | 予約カレンダー（メイン） |
| `{Web App URL}?page=cancel` | 予約キャンセル |
| `{Web App URL}?page=change` | 予約変更 |

## スプレッドシート構成

### 予約一覧
予約ID / 受付日時 / 予約日 / 予約時間 / 氏名 / 電話番号 / メールアドレス / メニュー / 料金 / ステータス / 備考 / カレンダーイベントID / リマインダー送信済みフラグ

### メニューマスタ
メニューID / メニュー名 / 所要時間（分） / 料金

### 設定
設定項目 / 設定値（キー・バリュー形式）

### 臨時休業日
日付 / 理由

### キャンセル・変更履歴
処理日時 / 予約ID / 氏名 / 元の予約日時 / 処理種別 / 変更後日時

### ダッシュボード
GASで自動集計・更新されるシート

---

## 予約IDの形式

`RSV-YYYYMMDD-XXX`

- RSV：固定プレフィックス
- YYYYMMDD：予約日
- XXX：同日の連番（001から）

## テストメール送信

1. 設定シートに「管理者メールアドレス」を入力
2. メニュー「⚙️ 予約ツール設定」→「テストメール送信」
3. 設定したアドレスにテスト予約確認メールが届きます

---

## 注意事項

- デプロイ後にコードを変更した場合は、「新しいデプロイ」で再デプロイする必要があります
- 同時受付数を超える予約は自動的にブロックされます
- 臨時休業日は「臨時休業日」シートに日付を追加するだけで反映されます
- メール送信はGmailの1日あたりの送信制限（無料アカウント: 100通/日）に従います
