## セットアップ手順

### 1. スプレッドシートを作成

1. [Google スプレッドシート](https://sheets.google.com) を開く
2. 「空白のスプレッドシート」を新規作成

### 2. GASプロジェクトにコードを反映

#### clasp を使う場合

```bash
cd tools/[ツール名]/
cp .clasp.json.example .clasp.json
# .clasp.json の scriptId を自分のGASプロジェクトのIDに書き換える
clasp push
```

#### 手動でコピペする場合

1. スプレッドシートのメニュー「拡張機能」→「Apps Script」を選択
2. `src/` 配下の各 `.gs` ファイルの内容をGASエディタにコピペ

### 3. 初回実行

1. GASエディタまたはスプレッドシートから初回実行
2. 権限の承認が求められるので「許可」を選択
