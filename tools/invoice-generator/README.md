# 請求書・見積書 自動生成ツール（Google Apps Script）

フリーランス・個人事業主向けの、Google スプレッドシート + GAS で動作する請求書・見積書自動生成ツールです。

## 機能

- 請求書・見積書のワンクリック生成
- A4縦レイアウトでのPDF自動出力（Googleドライブに保存）
- 発行番号の自動採番（INV-YYYYMMDD-XXX / EST-YYYYMMDD-XXX）
- 消費税の自動計算（10%・8%・非課税対応）
- 顧客マスタ・品目マスタによるデータ管理
- 発行履歴の自動記録

## ファイル構成

| ファイル | 内容 |
|---------|------|
| `Code.gs` | メイン処理（書類生成・フォームリセット・ヘルプ表示） |
| `pdf.gs` | PDF出力・Googleドライブ保存 |
| `history.gs` | 履歴管理・採番・顧客データ取得 |
| `setup.gs` | 初回セットアップ・シート初期化 |
| `appsscript.json` | GASプロジェクト設定 |

## セットアップ手順

### 手順1: スプレッドシートを作成

1. [Google スプレッドシート](https://sheets.google.com) を開く
2. 「空白のスプレッドシート」を新規作成
3. 適当な名前をつける（例: 「請求書管理ツール」）

### 手順2: GASエディタを開く

1. メニュー「拡張機能」→「Apps Script」を選択
2. GASエディタが開きます

### 手順3: コードをコピペ

1. デフォルトの `Code.gs` の内容をすべて削除
2. 本ツールの `Code.gs` の内容をコピペ
3. 左サイドバーの「＋」→「スクリプト」で新しいファイルを追加:
   - `pdf`（pdf.gsの内容をコピペ）
   - `history`（history.gsの内容をコピペ）
   - `setup`（setup.gsの内容をコピペ）
4. `appsscript.json` を編集する場合:
   - GASエディタの「プロジェクトの設定」→「「appsscript.json」マニフェスト ファイルをエディタで表示する」にチェック
   - 左サイドバーに表示された `appsscript.json` を開き、内容を上書き

### 手順4: シートを初期化

1. GASエディタ上部の関数選択で `initializeSpreadsheet` を選択
2. 「▶ 実行」ボタンをクリック
3. 初回実行時は権限の承認が求められます。「権限を確認」→ 自分のアカウントを選択 → 「許可」
4. 5つのシート（顧客マスタ、品目マスタ、入力フォーム、出力シート、履歴管理）が自動作成されます

### 手順5: 初回セットアップ

1. スプレッドシートに戻り、ページを再読み込み
2. メニューに「📄 書類生成ツール」が追加されています
3. 「📄 書類生成ツール」→「初回セットアップ」を選択
4. 自社の情報（会社名、住所、振込先など）を入力

### 手順6: マスタデータの編集

- 「顧客マスタ」シートに取引先情報を追加・編集
- 「品目マスタ」シートにサービス・商品を追加・編集

## 使い方

1. 「入力フォーム」シートを開く
2. 書類種別（請求書 or 見積書）を選択
3. 顧客名をドロップダウンから選択
4. 発行日を入力（請求書の場合は支払期限も）
5. 品目をドロップダウンから選択し、数量を入力
6. 必要に応じて備考欄に記入
7. メニュー「📄 書類生成ツール」→「書類を生成する」を実行

## スプレッドシート構成

| シート名 | 説明 |
|----------|------|
| 顧客マスタ | 顧客ID / 会社名 / 担当者名 / 郵便番号 / 住所 / メールアドレス / 電話番号 |
| 品目マスタ | 品目ID / 品名 / 単価 / 単位 / 税区分（10%/8%/非課税） |
| 入力フォーム | 書類作成の入力画面 |
| 出力シート | 生成された請求書・見積書の表示 |
| 履歴管理 | 発行番号 / 書類種別 / 発行日 / 顧客名 / 合計金額 / PDFリンク / 発行日時 |

## 注意事項

- 初回実行時にGoogleアカウントの権限承認が必要です
- PDFは「請求書フォルダ」というフォルダに自動保存されます（Googleドライブのルートに作成）
- 自社情報はスクリプトプロパティに保存されるため、コードには含まれません
- 品目マスタに追加した品目は、入力フォームのドロップダウンに自動反映されます
